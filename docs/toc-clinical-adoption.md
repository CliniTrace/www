# Terms of Confidence (ToC) & Clinical Buy-in

## Goal
Make adoption easy for clinicians, administrators, and risk teams.

## ToC pillars
1) Workflow fit (time saved, fewer retakes)
2) Safety boundaries (non-diagnostic outputs, refusal conditions)
3) Transparency (confidence bands, overlays)
4) Governance (doctor-led rubric, audit trails)
5) Security (RBAC, encryption, retention)

## Pilot playbook
- Select one use case + 2–3 champions
- Define baseline metrics (retakes, note time, escalation time)
- Run 2–4 weeks
- Review weekly with Alysha (clinical director)
- Publish a pilot report + next-step plan

## Adoption assets
- quickstart guide
- clinician FAQ
- “what CliniTrace is/isn’t” slide
- escalation workflow chart
