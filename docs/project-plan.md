# Project Plan (12 months)

## Phase 1 — MVP + Pilot (Months 0–3)
**Deliverables**
- Clinical taxonomy + safe language policy
- Capture + quality gate
- Baseline measurement + overlay
- Longitudinal comparison (delta)
- Structured summary output
- Pilot dashboard

**Success metrics**
- reduced retakes
- reduced documentation time
- clinician satisfaction
- safety: refusal/edge-case handling

## Phase 2 — Validation + Hardening (Months 4–8)
- model improvements + calibration
- cohort performance monitoring
- drift/quality analytics
- exports (PDF + EHR-friendly text)
- RBAC, audit events, retention policies

## Phase 3 — Scale (Months 9–12)
- 10–20 clinic deployments
- partner integrations (telehealth providers)
- regulatory readiness pathway
- regional expansion playbook
