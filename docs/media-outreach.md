# Media, Outreach & PR Kit

## Positioning statement
CliniTrace helps clinicians capture consistent clinical images, structure documentation, and track progression over time — improving workflow and defensibility.

## 30-second pitch
CliniTrace is a doctor-led visual monitoring platform that turns subjective observation into structured, measurable documentation and time-based progression tracking—built for clinics and remote care.

## Press release template
**Headline:** CliniTrace launches doctor-led AI visual monitoring to improve documentation and longitudinal tracking  
**Body:** What it does, pilot announcement, safety boundaries, quote from clinical director, next steps.

## Outreach targets
- telehealth operators
- clinic groups
- home nursing networks
- diabetic care programs
- health innovation hubs

## Email script (short)
Subject: Pilot partnership — structured wound/skin monitoring  
Body: 3 bullets value + 2-week pilot ask + call booking link.
