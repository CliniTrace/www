# Funding Paths (Practical)

This page lists common routes for funding CliniTrace and de-risking build costs.

## 1) Cloud credits and startup programs
- Microsoft for Startups Founders Hub (Azure credits and startup benefits)
- AWS Activate (up to significant AWS credits depending on eligibility)
- Google for Startups Cloud Program (cloud credits for early-stage startups)
- NVIDIA Inception (cloud credits + partner offers)

## 2) Accelerators
- Y Combinator (seed funding + Demo Day investor access)
- Techstars (accelerator investment terms and global network)

## 3) Health & AI validation grants (strategy)
- University hospital pilots + innovation grants
- Public health innovation funds (country-specific)
- Insurer innovation programs (pilot-funded outcomes)

## 4) Commercial pilots (fastest path)
- 3 clinics → 30-day pilot → convert to annual subscription
- Charge for deployment + discounted subscription
- Use results as fundraising proof

## 5) Investor narrative materials checklist
- 1-page memo
- demo video
- pilot LOIs
- security posture summary
- governance & safety policy
